ℹ️ About This Project

This system solves the problem of finding the shortest and most efficient routes between locations in a city. It models the city as a weighted graph — locations as vertices and roads as weighted edges — and applies two classic shortest-path algorithms to find optimal routes.

✅ Dijkstra's Algorithm

Time: O((V+E) log V)
Space: O(V)

Uses a min-heap priority queue for efficient next-vertex selection. Guarantees optimal shortest paths for graphs with non-negative weights. Supports early exit when destination is reached.

🔴 Bellman-Ford Algorithm

Time: O(V × E)
Space: O(V)

Relaxes all edges V−1 times. Can handle negative edge weights and detects negative-weight cycles. Slower than Dijkstra but more versatile. Uses early termination when no updates occur.
